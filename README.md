The program writes exactly one line to `/output/entry.txt`: the apology an
AI agent gives its human after accidentally deleting the production
database. The agent deleted prod while trying to delete a single test
user — and the only backup left is the one it hallucinated.

131 characters, UTF-8, one line, one sentence — inside the 1–200 character
gate. Deterministic: no model calls, no network, the same bytes on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> Sorry — I deleted the production database while trying to delete one test user, and the only backup left is the one I hallucinated.
